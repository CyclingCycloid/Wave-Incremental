# 维度折叠器：二十四胞体动画

本目录保存对话中选定的二十四胞体方案，供主代码维护者审查和接入。

## 查看效果

直接双击 `index.html`。预览可独立运行，不需要构建游戏或启动服务器；页面提供暂停／播放按钮，并跟随系统深浅主题。

- `index.html`：完整的独立预览，包含样式与脚本。
- `preview-source.html`：可编辑的原始动画片段，只保留选定的二十四胞体。
- `build-preview.mjs`：无第三方依赖的预览生成工具，只写本目录的 `index.html`。

预览不读取游戏存档，也不参与 CM、TP、频率或其他资源计算。

修改动画片段后，在仓库根目录运行 `node Issue/help/dimension-24cell/build-preview.mjs`，即可同步独立预览。生成页面不加载外部脚本、字体或网络资源。

## 选定的外观

- 四维二十四胞体：24 个顶点、96 条边。
- 橙色前景、灰色后景；缓慢旋转，利用透视与明暗表现内部结构。
- 默认速度 `0.65`、图形大小 `1`、初始时间参数 `2.3`，与选定的对话预览一致。
- 画布透明；预览外框与背景是展示容器，接入时可使用维度页面自身的背景。

## 接入参考

几何来源与绘制入口都集中在 `preview-source.html` 的脚本中：

1. `cell24()` 在初始化时生成几何数据。
2. `projectedVertices(view)` 完成四维旋转、四维到三维投影及屏幕投影。
3. `draw(view)` 按深度绘制固定数量的边与顶点。
4. `schedule()` / `frame()` 控制动画推进。

正式接入时，将画布放在维度页面的标题与 CM 信息附近；将主题颜色接到游戏样式变量，将启停条件接到维度标签页的可见状态。展示外框、方案标识、暂停按钮以及可选的对话控件可按正式界面需要处理。

`window.openai` 的可选调用用于对话预览的状态保存，`Tweak` 用于对话中的外观调整；动画计算不依赖它们。普通浏览器下仅运行动画与暂停按钮，正式游戏接入时可移除这两类预览适配代码。

## 性能约束

- 几何数据只生成一次，不随 CM 或 TP 的数量增加。
- 绘制上限为每秒 30 帧；实际成本仍取决于设备与画布尺寸。
- 像素比例上限为 1.5，避免高分辨率屏幕扩大绘制负担。
- 页面隐藏或画布离开可视区域时停止动画；恢复显示后继续。
- 系统启用减少动态效果时默认显示静态图，也可手动播放。
- 动画按真实时间推进，与游戏时间倍率分开。
